# ReachAI demo flow (2–3 minutes)

This walkthrough uses only the approved fictional demo prospect. No email is sent at any point.

## 0:00 — Open the dashboard

Open the ReachAI dashboard and briefly point out the **Strands Agent · Powered by Amazon Bedrock** cue in the sidebar. Mention that the dashboard uses simulated hackathon-demo data and that the app creates reviewable outbound, not automatic sends.

## 0:20 — Create a campaign

Open **Campaigns**, then select **New campaign**. In the demo-prospect selector, choose **Rahul Sharma · Acme Technologies**.

Use the supplied ReachAI product description and the target customer description for sales leaders at growing B2B SaaS companies, then select **Generate outreach**. Point out the compact drafting path: **ReachAI UI → Strands Agent → Amazon Bedrock → Structured campaign**.

## 0:50 — Show verified company context

Point out the **Verified company context used** indicator. In the context card, show that the campaign is grounded in these approved fictional facts:

- Acme Technologies provides workflow automation software for growing businesses.
- The company is expanding its sales organization.

## 1:15 — Explain the message

Open the **WHY THIS MESSAGE?** evidence rail. Explain that the reasons connect Acme's sales-team expansion, Rahul's VP Sales role, Acme's B2B SaaS industry, and its workflow-automation context to relevant outbound—without invented personal details or hidden reasoning.

## 1:35 — Review the sequence

Show the Day 0 email, then show the visual sequence: **Today — Initial outreach**, **Day 3 — Follow-up**, and **Day 7 — Follow-up**. Confirm there are exactly two follow-ups.

Select **Edit**, make a small wording adjustment if desired, and select **Save edits**. Then select **Approve draft** to demonstrate the human-review checkpoint. Approval is simulated and does not send an email.

## 2:15 — Show analytics

Open **Analytics** and close by reiterating that all dashboard metrics are simulated. ReachAI's demo value is the controlled workflow: local fictional context, structured AI drafting, and human review before any hypothetical outreach.
